# Go Deeper rule
Each LESSON.md supplies **at least two appropriate supplementary resources** (Lesson 01 currently uses two): one focused article/reference (often Real Python) and one official documentation or short course. Real Python may require paid access; membership is optional. Use the other link if access is unavailable.

Supplementary reading helps when traveling, caring for family or studying on a phone. A 5-minute recap earns a journal entry, **not a passed programming assessment**.

Preferred sources: Real Python, official Python/FastAPI/pytest/Docker/LangChain documentation, Codecademy, ZTM Bytes, DeepLearning.AI. Course URLs may change: verify access before relying on them. Never redistribute third-party course content in this repository.
