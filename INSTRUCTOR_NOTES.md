# Instructor note (not secret answer key)
The tests in `practice/test_ticket_rules.py` are intentionally not part of the default test run (`pytest.ini` limits discovery to tests/). `python -m pytest -q` checks repo integrity. To test your assignment, run `python -m pytest -q practice/test_ticket_rules.py` after implementing it. Do not mistake the repository's initial green structure tests for proof that student exercises are completed.

This is a usable **v1 course pack**: all 20 original lesson chapters and assignments exist, and the staged projects are specified. Deep interactive features (web GUI, automatic grading, fully implemented 20 project-specific challenge suites) are not included. Students and tutor should gradually add instructor-reviewed exercises as the course proceeds.
