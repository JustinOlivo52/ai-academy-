# Independent assessments
For each stage, ask your tutor to generate a **new unseen variation** of the concepts but require it to preserve instructor-led grading. Submit: code, test evidence, edge-case reasoning, a short PR-style summary. Do not mark passed solely based on generated tests.

Graduation simulation: given a bug report about ticket priority unexpectedly changing, reproduce it, create a regression test, fix it, explain tradeoffs and update docs. Aim to finish a small correct change, not a huge feature.
